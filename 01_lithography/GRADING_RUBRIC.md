# Grading Rubric (100 pts)

## A. Reproducibility (20 pts)
- One-command run reproduces your final plots/metrics (10)
- Clean config + documented parameters (10)

## B. Baseline Understanding (20 pts)
- Correct baseline plots and interpretation (10)
- Clear definition of CD and extraction method (10)

## C. Imaging / RET Extension (20 pts)
- Correct implementation of ≥1 imaging/RET feature (10)
- Quantitative comparison vs baseline (10)

## D. Resist / Process Extension (20 pts)
- Correct implementation of ≥1 resist/process feature (10)
- Shows how it changes window/sensitivity (10)

## E. Manufacturability Metric (20 pts)
- Implements ≥1 metric (NILS/window area/CDU etc.) (10)
- Uses it to justify recipe choice (10)

## Bonus (up to +10)
- Optimization loop (maximize window area under constraints)
- 2D contact pattern with meaningful discussion
- LER/yield analysis beyond the baseline

## Bonus (Spin-coating / process integration) (+5)
- Demonstrates spin-coating thickness simulation and a justified coupling to lithography outcomes
