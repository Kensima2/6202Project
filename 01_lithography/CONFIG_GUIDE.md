## 🎯 目标 & 公差

### `target_cd_nm`
- **含义**：Critical Dimension (临界尺寸) - 目标线宽
- **单位**：纳米 (nm)
- **当前值**：45 nm
- **范围**：通常 20～500 nm（根据工艺代数）
- **影响**：决定了工艺窗口的绿色区域（合格范围）
- **工业意义**：代表半导体工艺节点的特征尺寸

### `cd_tol_nm`
- **含义**：CD 公差（允许偏差）
- **单位**：纳米 (nm)
- **当前值**：5 nm
- **范围**：通常为目标 CD 的 5%～15%
- **合格范围**：[target_cd_nm - cd_tol_nm, target_cd_nm + cd_tol_nm]
  - 例如：[40 nm, 50 nm]
- **物理意义**：如果实际 CD 落在此范围内，工艺视为通过（"Pass"）

## 🎨 图案参数

### `pattern`
- **含义**：掩膜图案类型
- **可选值**：
  - `"line_space_1d"` - 一维周期线条/间距（推荐入门）
  - `"contact_2d"` - 二维接触孔阵列（更复杂）
- **当前值**：`"line_space_1d"`
- **影响**：决定后续工艺流程的维度

### `pitch_nm`
- **含义**：图案周期 = 线宽 + 间距（一个重复单位的总长度）
- **单位**：纳米 (nm)
- **当前值**：90 nm
- **范围**：通常 60～500 nm
- **与分辨率的关系**：pitch 越小 → 需要更高的 NA + 更优的光学系统
- **计算**：线宽 = pitch × duty_cycle

### `duty_cycle`
- **含义**：占空比 = （线宽或孔径）/ 周期
- **单位**：无（比例 0～1）
- **当前值**：0.5（50%）
- **范围**：0.3～0.7 （极端值会导致难以加工）
- **效果**：
  - 0.5：线宽 = 间距（对称）
  - <0.5：线条较窄
  - >0.5：线条较宽

### `mask_tone`
- **含义**：掩膜的透光方式
- **可选值**：
  - `"bright"` - 特征部分透光（亮），背景阻光（暗）
  - `"dark"` - 特征部分阻光（暗），背景透光（亮）
- **当前值**：`"dark"`
- **工业对应**：取决于掩膜工艺和光刻胶性质
- **影响**：改变掩膜与光学系统的交互

## 💡 光学参数

### `wavelength_nm`
- **含义**：曝光光的波长
- **单位**：纳米 (nm)
- **当前值**：193 nm（深紫外 DUV）
- **常见值**：
  - 365 nm - i线（低端工艺，已淘汰）
  - 248 nm - KrF 准分子激光
  - 193 nm - ArF 准分子激光（现代主流，极紫外前的标准）
  - 13.5 nm - EUV（极紫外，最先进工艺）
- **物理意义**：波长越短 → 分辨率越高（λ 越小）

### `na`（Numerical Aperture，数值孔径）
- **含义**：光学系统的收光能力（与分辨率/景深权衡）
- **单位**：无（比例）
- **当前值**：0.85
- **范围**：
  - 0.4～0.75 - 传统工艺
  - 0.85～1.35 - 现代高分辨率
- **关系**：
  - NA ↑ → 分辨率 ↑，但景深 ↓（对焦容限变小）
  - 分辨率 ~ λ/NA
- **工业意义**：高数值孔径需要浸液光刻或极紫外技术

### `sigma_in` / `sigma_out`
- **含义**：部分相干性参数 - 定义光源在瞳孔平面的分布形状
- **单位**：无（标准化相对于瞳孔半径）
- **当前值**：
  - sigma_in = 0.3（内环半径）
  - sigma_out = 0.7（外环半径）
- **配置类型**：环形照明（Annular illumination）
  - 内环点光源：0.0～sigma_in
  - 外环点光源：sigma_in～sigma_out
- **效果对比**：
  - σ_in=0, σ_out=1.0：常规照明（所有方向均匀）
  - σ_in=0.3, σ_out=0.7：环形照明（提高对比度）
  - σ_in=σ_out（偶极子）：特定方向优化

### `n_source_samples`
- **含义**：光源采样点数 - 用蒙特卡洛方法模拟部分相干照明
- **单位**：点数（整数）
- **当前值**：41
- **范围**：12～100（越多越精确但计算越慢）
- **原理**：在 [σ_in, σ_out] 环形区域随机采样 n 个点，各自计算coherent像，最后平均
- **精度权衡**：
  - 12 - 快速演示
  - 41 - 平衡精度和速度
  - 100+ - 高精度研究

## 🫖 光刻胶参数

### `resist_type`
- **含义**：光刻胶的极性
- **可选值**：
  - `"positive"` - 曝光部分被显影液溶解
  - `"negative"` - 未曝光部分被显影液溶解
- **当前值**：`"positive"`
- **工业主流**：现代工艺多采用正性胶（便于 OPC 和工艺控制）

### `develop_threshold`
- **含义**：显影阈值 - 决定曝光后光刻胶是否被显影掉
- **单位**：无（归一化强度 0～1）
- **当前值**：0.5
- **物理模型**（简化）：
  - 对于正性胶：如果光强度 I > threshold，则显影掉（resist = 0）
  - 对于负性胶：如果光强度 I < threshold，则显影掉
- **实际对应**：阈值越高 → 需要更强的光才能显影 → CD 可能变小

### `peb_blur_nm`
- **含义**：曝光后烘烤(Post-Exposure Bake, PEB) 的热扩散模糊程度
- **单位**：纳米 (nm)（高斯模糊的标准差 σ）
- **当前值**：10 nm
- **范围**：5～50 nm（根据胶体厚度和烘烤温度）
- **物理意义**：
  - 曝后烘烤是化学放大光刻的关键步骤
  - 光酸在热作用下扩散，扩散距离与 √(D·t) 成正比
  - 这里用高斯模糊来近似扩散效果
- **工艺影响**：
  - peb_blur ↑ → CD ↑（线变粗、孔变大）
  - peb_blur ↓ → CD ↓（线变细、孔变小）

## 📊 扫描控制

### 剂量扫描（Dose Sweep）

```json
"dose_sweep": {
  "start": 0.7,     // 起始剂量（相对值）
  "stop": 1.3,      // 终止剂量
  "num": 31         // 采样点数
}
```

- **含义**：模拟不同曝光能量的效果
- **工艺窗口**：形成过程窗口图的**横轴**
- **扫描范围**：[0.7, 0.72, 0.74, ..., 1.3]（共 31 个点）
- **物理意义**：
  - dose < 1.0：欠量，光强不足，CD 偏小
  - dose = 1.0：标准剂量
  - dose > 1.0：过量，光强过多，CD 偏大
- **实际应用**：工厂会测试这个范围找到最优剂量

### 焦点偏移扫描（Defocus Sweep）

```json
"defocus_sweep_nm": {
  "start": -100,    // 离焦（负值向下）
  "stop": 100,      // 过焦（正值向上）
  "num": 41
}
```

- **含义**：模拟焦点不准确时的效果
- **工艺窗口**：形成过程窗口图的**纵轴**
- **扫描范围**：[-100, -95, ..., 0, ..., 100] nm（共 41 个点）
- **物理意义**：
  - defocus < 0：晶圆离焦点太近，像变差
  - defocus = 0：焦点正好，最优情况
  - defocus > 0：晶圆离焦点太远，像变差
- **景深**：焦点偏移在 ±50 nm 内 CD 仍在公差范围 → 景深 ~100 nm

## 🔧 数值网格

### `dx_nm`
- **含义**：空间采样间距（像素大小）
- **单位**：纳米 (nm)
- **当前值**：2 nm/像素
- **范围**：1～5 nm（需要满足 Nyquist 采样定理）
- **影响**：
  - dx ↓（更小）→ 分辨率 ↑，但内存/时间 ↑（平方关系）
  - dx ↑（更大）→ 计算快，但可能丢失细节
- **经验法则**：dx < λ/10 是合理的

### `sim_pitches`
- **含义**：仿真范围包含多少个周期
- **单位**：周期数（整数）
- **当前值**：4
- **总仿真宽度计算**：sim_pitches × pitch_nm = 4 × 90 = 360 nm
- **影响**：
  - sim_pitches ↑ → 计算范围 ↑，能看到周期性阵列的边界效应
  - sim_pitches ↓ → 更快，但边界效应可能有误
- **建议**：通常取 3～5 个周期（平衡精度和速度）

## ⚙️ RET 工艺优化

### PSM（相移掩模，Phase Shift Mask）

```json
"ret": {
  "psm": {
    "enabled": false,           // 改为 true 启用
    "phase_rad": 3.14159,       // π相移（弧度）
    "region": "spaces"          // "spaces"(间距相移) 或 "lines"(线条相移)
  }
}
```

- **含义**：在掩膜某些区域刻蚀沟槽，产生π相位差
- **效果**：
  - 提高图像对比度（相邻特征对相消干涉）
  - 扩大工艺窗口（过程窗口面积 ↑ 30%～50%）
- **工业应用**：现代工艺常用（32nm 以下标准）

### OPC（光学邻近效应校正，Optical Proximity Correction）

```json
"ret": {
  "opc": {
    "enabled": false,           // 改为 true 启用
    "mask_bias_nm": 0.0         // 正值扩大特征，负值缩小特征
  }
}
```

- **含义**：预先修改掩膜尺寸补偿光学系统的邻近效应
- **实现**：
  - 1D 模式：直接调整 duty_cycle
  - 2D 模式：形态学膨胀或腐蚀（dilate/erode）
- **效果**：
  - mask_bias > 0：特征变大
  - mask_bias < 0：特征变小
- **工业意义**：消除图案间的相互影响（小孔周围被邻近特征遮挡）

## 📈 常见修改场景

### 场景 1：我想提高分辨率

**目标**：制造更小的特征 (例如 45nm → 32nm)

**修改方案**：
```json
{
  "target_cd_nm": 32,              // ↓ 目标变小
  "na": 0.93,                      // ↑ 增加数值孔径（0.85 → 0.93）
  "pitch_nm": 64,                  // ↓ 减小周期
  "peb_blur_nm": 7,                // ↓ 减少热扩散
  "wavelength_nm": 193             // 保持不变（或升级到 EUV）
}
```

**预期结果**：
- CD 小但需要更好的工艺控制
- 景深变浅，焦点容限 (DOF) 变小

---

### 场景 2：我想扩大工艺窗口（提高良率）

**目标**：容错能力增强，CD 范围 [35, 55]nm

**修改方案**：
```json
{
  "cd_tol_nm": 10,                 // ↑ 扩大公差
  "peb_blur_nm": 8,                // ↓ 微调热扩散
  "sigma_in": 0.2,                 // ↓ 缩小内环
  "sigma_out": 0.85,               // ↑ 扩大外环（但不超过 1.0）
  "ret": {
    "psm": {"enabled": true},      // ✓ 启用相移掩模
    "opc": {"enabled": true, "mask_bias_nm": 5}  // ✓ 启用 OPC
  }
}
```

**预期结果**：
- 工艺窗口面积 ↑（绿色区域变大）
- 可容忍剂量偏差和焦点偏移
- 工艺更稳定，良率更高

---

### 场景 3：我想加快模拟速度

**目标**：快速演示或参数扫描

**修改方案**：
```json
{
  "dx_nm": 4,                      // ↑ 从 2 → 4 nm（4 倍快）
  "n_source_samples": 12,          // ↓ 从 41 → 12（采样少）
  "sim_pitches": 2,                // ↓ 从 4 → 2（范围小）
  "dose_sweep": {"num": 15},       // ↓ 从 31 → 15
  "defocus_sweep_nm": {"num": 21}  // ↓ 从 41 → 21
}
```

**预期结果**：
- 总计算时间从 ~100s 降到 ~5-10s
- 精度略有降低，但趋势保留

---

### 场景 4：我想优化某个特定条件

**目标**：针对"精细孔径"优化

**修改方案**：
```json
{
  "pattern": "contact_2d",         // 改用 2D 模式
  "pitch_nm": 200,                 // 孔径周期
  "duty_cycle": 0.3,               // 小孔（孔径 = 60nm）
  "na": 0.93,                      // 推荐高 NA
  "wavelength_nm": 193,
  "peb_blur_nm": 12,               // 可能需要偏大（小孔易填平）
  "ret": {
    "psm": {"enabled": true, "region": "background"}  // 背景区相移
  }
}
```

## 🔍 调试技巧

| 问题 | 症状 | 修改建议 |
|------|------|--------|
| CD 太小 | 实际线宽 < target | ↑ peb_blur_nm，↑ dose_sweep.start，↓ na |
| CD 太大 | 实际线宽 > target | ↓ peb_blur_nm，↓ dose_sweep.start，↑ develop_threshold |
| 工艺窗口为空（无绿色区域） | Pass region 不存在 | ↑ cd_tol_nm，调整 peb_blur/sigma，启用 PSM/OPC |
| 焦点敏感 | defocus 范围很小 | ↑ na（增加光学强度），↓ peb_blur_nm |
| 剂量敏感 | dose 范围很小 | 调整 develop_threshold，优化 sigma_in/out |
| 模拟不收敛/图形全黑 | 无有效信号 | ↓ develop_threshold（降低显影阈值）|
| 模拟太慢 | > 1 分钟 / 窗口 | 减小 sim_pitches, n_source_samples, dx_nm |
